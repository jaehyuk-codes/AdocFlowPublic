AdocFlow Privacy Policy

Effective: September 18, 2026 · Applies to: the AdocFlow desktop app for Windows (Microsoft Store and installer builds)

In short. AdocFlow has no accounts and does not collect or send any information that identifies you. Your documents and settings stay on your device.

It talks to the network for two things only: sending the source text of a diagram to a diagram server so it can be rendered, and, in installer builds, checking for updates. Both are described below.

1. What we do not collect

  • There is no sign-up or sign-in. The app never asks for a name, email address or other personal details.
  • No usage statistics, analytics, advertising identifiers or crash reports are collected or transmitted.
  • The content of your documents is never sent to any server the developer can read.

2. What is stored on your device

3. Network communication

3.1 Diagram rendering (Kroki)

  • To draw diagrams other than Mermaid (PlantUML, Graphviz, D2 and so on), the app sends only the source text of that diagram block over HTTPS to the configured Kroki server and receives an SVG. Mermaid diagrams are rendered on your device and are not sent anywhere.
  • The default server is the public service at https://kroki.io, operated by a third party under its own policy.
  • You can change the server in Settings. With your own or your organisation's Kroki server, diagram text goes only there.
  • A document without diagram blocks sends nothing.

3.2 Update check (installer builds only)

  • Builds installed with the MSI or NSIS installer contact an update server to see whether a newer version exists. The request carries the operating system, CPU architecture and current app version, and nothing that identifies you.
  • The Microsoft Store build has no updater. The Store handles installation and updates.

3.3 Everything else

  • The app does not fetch remote URLs written in your documents (images, links, includes) on its own, and following an external link in the preview does not open external pages inside the app.
  • The libraries used for preview rendering, syntax highlighting and math are bundled with the app and work offline.

4. File access and export

  • The app reads and writes only the folder you opened, the files in it, and files you open directly.
  • HTML and PDF export and printing happen only when you start them, and the output goes where you choose.
  • The clipboard is used only when you invoke a copy action.
